# Script Shed Homepage Dark Clone

Static darker homepage files for `https://mattlivingston.com/shed/`.

This clone was created from `script-shed-homepage` without modifying the original folder.

Current listed scripts:

- Download Vault
- Click Counter
- Form Inbox

Files:

- `index.html`
- `styles.css`
- `assets/download-vault-preview.png`

The page assumes these URLs after upload:

- `/shed/download-vault/`
- `/shed/download-vault/download-vault-1.0.0.zip`
- `/shed/click-counter/`
- `/shed/click-counter/downloads/click-counter-1.0.0.zip`
- `/shed/form-inbox/`
- `/shed/form-inbox/downloads/form-inbox-1.0.0.zip`

If the Download Vault ZIP or product page live somewhere else, update the matching links in `index.html`.
