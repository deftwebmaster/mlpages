Quick Setup

Built for the classic webmaster workflow.

Download the ZIP, upload the files, edit the config, and start using the script from your own hosting account.

  1. Download the script ZIP. Each Script Shed release includes source files, docs, and setup notes.
  2. Upload it to your hosting account. Use FTP, SFTP, cPanel File Manager, or your preferred deployment method.
  3. Edit the configuration file. Set paths, URLs, passwords, and options in one documented place.
  4. Open the admin page. Follow the README for permissions, security checks, and first-use steps.

What belongs in the Shed?

Small PHP tools that solve a real website-owner problem without trying to become a platform.

  • Installerless or very close to it
  • Plain documentation
  • Local storage when practical
  • Responsive admin screens
  • Security-conscious defaults
