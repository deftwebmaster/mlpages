Mitigation playbook

How to reduce your fingerprint

Use fingerprint resistance, not only privacy mode
Private windows usually clear storage after the session, but they do not automatically normalize canvas, WebGL, fonts, timezone, or hardware signals.
Be careful with canvas, WebGL, and audio
These APIs expose rendering and processing differences from your graphics stack, drivers, fonts, and audio pipeline. They are some of the strongest fingerprint inputs.
Reduce permission surfaces
Camera, microphone, notification, and geolocation states can all add context. Keep defaults strict and grant access only when a site truly needs it.
Limit extensions and custom fonts
Extensions, unusual installed fonts, and custom browser settings can make you stand out. A boring browser profile is often harder to separate from the crowd.
Use a VPN for network privacy
A VPN can hide your IP address from sites, but it does not erase browser-level fingerprints. Pair it with browser protections for a more complete privacy posture.
Separate identities by browser profile
For sensitive work, use separate browser profiles or browsers so logins, extensions, storage, and fingerprint surfaces do not all reinforce the same identity.
