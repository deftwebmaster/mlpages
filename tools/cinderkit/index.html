Where it fits

Start with CinderKit. Finish with Website Launch Kit.

CinderKit gives you the editable site. Website Launch Kit gives you the launch files around it: meta tags, sitemap, robots, legal drafts, headers, and final preflight checks.

Inside the ZIP

The useful parts, already wired together.

01

Complete landing page

Hero, proof points, feature cards, steps, FAQ, final CTA, and a clean 404 page with the same visual system.

02

Plain files

No bundler, framework, lockfile, package manager, or dev server required. It is just HTML, CSS, and a small optional JavaScript file.

03

Deploy presets

Includes root `_headers` syntax for Cloudflare Pages and Netlify, plus `vercel.json` for Vercel response headers.

04

Launch hygiene

Robots, sitemap, social image, favicon, README checklist, reduced-motion support, accessible nav, and basic form protection.

Workflow

A cleaner path from idea to live page.

1

Download the starter

Unzip CinderKit and open `index.html` locally. Replace the demo copy with your product, service, portfolio, or experiment.

2

Run launch preflight

Use Website Launch Kit to generate metadata, sitemap entries, security headers, legal drafts, and the launch checklist.

3

Deploy the static files

Drop the folder into Cloudflare Pages, Netlify, Vercel, GitHub Pages, or any host that serves static HTML.
